1. Unicode locale-tailored casing (Turkish/Azeri, Lithuanian — needs a locale parameter threaded through every casing call), NFC/NFD normalization, and grapheme-cluster segmentation (UAX #29) so `reversed`/`split` operate on graphemes rather than scalars.
2. "with" style scoped blocks.
3. Store and load binary AST instead of reparsing.
4. Store and load generated bytecode instead of recompiling.
5. `zero`/`one`/`hash` have no impls for the 128-bit types (`int128`, `uint128`, `float128`): a reachable module is compiled in full and neither backend has a representation for them yet, so an `impl zero for int128` in `std.traits` would break every program.
6. A module-qualified static used with an index, such as `t.m.xs[1]` for `static let xs: list[int64]` in module `t.m`, gets no checked type. Reading or assigning it fails in lowering with "no concrete checked type is available for this node". The bare `xs[1]` works.
7. `for x in &mut v` over a `var v: list[int64]` is rejected with "cannot iterate over `(...)` by value", which names neither `v` nor what to write instead.
8. The specification does not say whether the bindings of `match`, `if let`, `while let`, and `for` patterns can be changed. `=` on them is rejected, but a `&mut` borrow or a `mut self` call is accepted when the binding owns its value (one bound through a reference is covered by the rule for `&T`). Chapter 3 should state the rule, and the checks should follow it.
