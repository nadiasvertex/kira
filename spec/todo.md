The `0` alternative binds no `y`, so the core has no binding to read, and the program fails with an internal compiler error at lowering ("`y` names no local and no recorded function"). 61. The checker accepts a comprehension over a value that is not iterable, `for x in xs => x` with `xs` of a struct type that has no iterator, and leaves the element type open. Lowering then reports a feature gap, "no concrete checked type is available for this node (`list[_]` holds `_`)", which does not name the cause. A `for` statement over the same value is item 53. The checker should reject both.
62. The checker accepts `await yield` in a function that is not `async`, because `infer_await` returns `unit` for it before the `async` check. Chapter 26 makes `await` outside an `async` function an error. The adapter refuses it there with a feature gap ("`await yield` can only be used in an `async def` or an `async:` block"), which wrongly calls the program valid. The checker should report the same error it reports for any other `await`.
